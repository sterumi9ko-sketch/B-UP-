# 图片资源说明（ASSETS）

这份文档说明网站的图片放在哪里、怎么命名、需要多大尺寸，以及**图片缺失时会怎样显示**。
你只需要按下面的规则把图片放进对应目录，网站就会自动调用，**不需要改任何代码**。

---

## 一、目录结构

```text
public/
  images/
    ups/              ← UP 主头像（你主要需要准备的就是这里）
      up_001.webp
      up_002.webp
      ...
    backgrounds/      ← 备用背景图（当前版本用 CSS 渐变实现，可以不放）
    decorations/      ← 装饰插画（当前版本未使用，预留）
    placeholders/
      up-placeholder.svg   ← 通用占位图（已提供，不要删除）
```

> Vite 会把 `public/` 下的文件原样复制到 `dist/`，所以路径里**不写 `public`**：
> 例如文件放在 `public/images/ups/up_001.webp`，
> 网站里引用的路径是 `images/ups/up_001.webp`。

---

## 二、头像命名规则

**文件名 = UP 主编号 + 扩展名**，例如 `up_001.webp`。

站点会按下面的顺序依次尝试，找到哪个用哪个：

1. `images/ups/<编号>.webp`
2. `images/ups/<编号>.png`
3. `images/ups/<编号>.jpg`
4. `images/ups/<编号>.jpeg`
5. `images/ups/<编号>.svg`
6. `images/ups/<编号>.avif`

所以：**扩展名不是 webp 也没关系**，只要编号对就行。

### 想用别的文件名？

在对应的档案文件（`src/data/ups/group*.ts`）里给那位 UP 主加上 `image` 字段即可：

```ts
{
  id: 'up_001',
  uid: 63231,
  name: '泛式',
  image: 'fanshi-avatar',          // → images/ups/fanshi-avatar.webp / .png / …
  // image: 'https://example.com/a.png',   // 也支持完整网址
  // image: '/images/custom/a.png',        // 支持以 / 开头的绝对路径
}
```

## 四、推荐图片规格

| 用途 | 推荐尺寸 | 比例 | 说明 |
|---|---|---|---|
| UP 主头像 | 512 × 512 px | 1:1 | 正方形，主体居中 |
| 分享图内头像 | 300 × 300 px 以上 | 1:1 | 分享图里会缩放绘制，太小的图会模糊 |
| 背景图（可选） | 1920 × 1080 px | 16:9 | 当前版本用 CSS 渐变，不放也不会报错 |

其他建议：

- 单张头像控制在 **200 KB 以内**，整站加载更快（B 站用户大多用手机打开）。
- 优先用 `webp`，体积最小；`png` 适合有透明通道的图。
- 头像最好是正方形，非正方形会被 `object-fit: cover` 居中裁剪。

## 五、图片缺失时会怎样

**不会出现破损图片图标。** 具体分两种情况：

1. **所有候选路径都不存在** → 自动降级为「文字占位头像」：
   取昵称首字（例如「泛」），画在暖色底上，由浏览器内联 SVG 生成，
   与整站配色一致，视觉上不会突兀。

2. **分享图（Canvas 导出）** → 同样使用文字占位头像绘制，
   所以**即使一张图片都没有，分享图功能也完全可用**。

相关实现：`src/core/assets.ts`（页面用）与 `src/share/card.ts`（分享图用）。

## 六、版权提醒（重要）

- 本站**不会**自动下载、抓取或转载任何 UP 主的头像、视频封面与截图。
- 如果你准备自行放入头像，请确认你有使用权（例如获得授权、使用官方公开素材，或自己绘制）。
- 在未获得授权的情况下，建议：
  - 保持默认的文字占位头像（已经是可用状态）；
  - 或使用自己绘制的、不指向特定真人的风格化插画。
- 视频截图、B 站官方素材、他人二创作品通常都有版权限制，请勿随意放入。

## 七、一次放入多张图片

准备好一批头像并按编号命名后，直接复制到 `public/images/ups/` 即可：

```powershell
# 假设你在项目根目录，头像都放在 D:\avatars 下并已按 up_001.webp 命名
Copy-Item D:\avatars\*.webp public\images\ups\
```

放好后运行 `npm run dev`，打开图鉴页检查效果即可，**不需要修改任何代码**。

---

## 八、换掉默认占位图

`public/images/placeholders/up-placeholder.svg` 是通用占位图，可以替换成你自己的设计，
只要保持文件名不变即可。

另外还有一种**动态生成**的文字占位头像（昵称首字 + 暖色底），
它由 `src/core/assets.ts` 的 `textAvatarDataUrl()` 生成，无需图片文件。
两者是互补关系：

- 某位 UP 主没有头像文件 → 用动态文字占位（不同人颜色和首字不同，更好区分）
- 需要一张通用兜底图（例如说明文档、分享图背景）→ 用 `up-placeholder.svg`
